# Eiendomsforvaltning Sør AS

Nettside for EFS med tjenestepresentasjon og scrollstyrte arkitektillustrasjoner.

## Filer

- `index.html`: innhold og sidestruktur
- `estate.css`: utforming og responsive visninger
- `estate.js`: scrollanimasjon og kontaktfunksjon
- `assets/`: illustrasjoner og logoer

Siden er statisk og trenger ingen bygging. Publiser mappen med `index.html` som startside.

Illustrasjonene er AI-genererte prinsippskisser, ikke godkjente prosjekttegninger.
Logoene tilhører de respektive selskapene.

Denne prosjektmappen inneholder bare nettsiden. Arbeidstegninger, interne dokumenter
og tidligere utkast inngår ikke.
